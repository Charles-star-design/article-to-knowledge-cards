# make-knowledge-cards

一个可直接安装的 OpenAI Codex Skill：把一篇文章转换成一组结构化的知识卡片。

## 1. 项目解决什么问题

读完一篇长文章后，手工整理复习卡片既费时又容易写成流水账：要么把整段话复制成一张卡，要么凭印象补上原文没有的内容。

这个 Skill 把整理工作标准化：从原文中提取真正重要的知识点，拆成一张一个知识点的卡片，并保证每张卡片都能追溯到原文。它只输出卡片，不编造、不硬凑、不写过程说明。

## 2. 主要功能

- **输入**：对话中粘贴的文章正文，或本地 `.md` / `.txt` 文件的路径。
- **输出**：Markdown 格式的 **5~8 张卡片**；原文知识点较少时按实际数量输出，并注明原因。
- **卡片结构**：每张卡片固定四个字段——标题、核心知识、简明解释、例子 / 自测问题。
- **质量约束**：
  - 只提取核心观点、定义、因果与结论，丢弃修辞和背景铺垫；
  - 一张卡片只讲一个知识点，并列成员（如"两种用途"）算作一个；
  - 重复表述合并为一张；
  - 不编造原文没有的事实、数字、例子或答案；
  - 5~8 是丰富文章的目标区间，不是必须凑满的配额。
- **明确不支持**：网页抓取、PDF、Anki 导出、图形界面。遇到这类输入会说明不支持，并请用户提供粘贴文本或 `.md` / `.txt` 文件。

项目结构极简，**没有任何脚本或第三方依赖**；全部行为由 Skill 指令驱动：

```
.
├── README.md
├── LICENSE                       # MIT 许可（与 SKILL.md 中的 license: MIT 一致）
├── .gitignore                    # 排除 .workbuddy/ 内部日志与临时文件
└── skills/
    └── make-knowledge-cards/
        ├── SKILL.md              # Skill 主体：触发条件、输出契约、工作流程、边界案例、示例
        └── agents/
            └── openai.yaml       # Codex 界面元数据：显示名、简介、默认提示词
```

## 3. 安装方法

Skill 就是一个含 `SKILL.md` 的目录。把 `skills/make-knowledge-cards` 整个目录复制到目标 skills 目录即可（Codex 用户级目录为 `~/.codex/skills/`，Windows 下即 `%USERPROFILE%\.codex\skills`）：

```bash
# 用户级安装：对所有项目生效
cp -R skills/make-knowledge-cards "$HOME/.codex/skills/"

# 项目级安装：随仓库分发给团队（Codex 从仓库根目录向上查找 .agents/skills/）
mkdir -p .agents/skills
cp -R skills/make-knowledge-cards .agents/skills/
```

Windows PowerShell 可用 `Copy-Item -Recurse` 完成同样的复制。安装后重启 Codex 或新开会话；用 `/skills` 查看已安装的 Skill，确认 `make-knowledge-cards` 出现即安装成功。

该目录遵循通用的 Agent Skills 格式，因此同样可放进 Claude Code 等其他兼容 agent 的 skills 目录（如 `~/.claude/skills/`）；`agents/openai.yaml` 只是 Codex 的可选界面配置，其他 agent 会忽略它。

## 4. 使用方法

安装后有两种触发方式：

- **自动触发**：直接粘贴文章并说明要做什么，Skill 会根据 `description` 自行匹配。
- **显式调用**：输入 `$make-knowledge-cards` 后接任务，精度更高。

示例：

> 用 make-knowledge-cards 把这篇文章做成知识卡片。

> 把 `notes/article.md` 转成复习卡片。

> $make-knowledge-cards 把下面这段文字整理成卡片：……

输入可以是粘贴的文字，也可以是本地 `.md` 或 `.txt` 文件的路径。输出直接显示在对话中，是一段 Markdown，不写入文件。

## 5. 输入输出示例

**输入**（粘贴的文章片段）：

> 睡眠不足会削弱免疫系统。研究发现，每晚睡眠少于6小时的人，接触感冒病毒后患病概率是睡足8小时者的四倍。此外，深度睡眠阶段身体会释放更多细胞因子，这类蛋白质帮助免疫细胞对抗感染。

**输出**：

> 来源：用户粘贴的片段；共 2 张卡片（原文知识点有限，未强行补足）。

### 卡片 1：睡眠不足削弱免疫防御

- **核心知识：** 睡眠不足会削弱免疫系统，使人更容易患病。
- **简明解释：** 原文指出睡眠不足对免疫防御有负面影响，是后文具体数据和机制的前提。
- **例子 / 自测问题：** 自测：根据原文，睡眠不足对人体免疫的总体影响是什么？答案要点：削弱免疫系统，更容易患病。

### 卡片 2：少于6小时睡眠使感冒概率增至四倍

- **核心知识：** 每晚睡眠少于6小时的人，接触感冒病毒后患病概率是睡足8小时者的四倍。
- **简明解释：** 这是原文给出的具体量化证据，用对比说明睡眠时长与患病风险的关系。
- **例子 / 自测问题：** 例子：原文对比了每晚睡少于6小时与睡足8小时两组人，前者患病概率是后者的四倍。

这个例子体现了三条规则：两个不同知识点被拆开，第三个次要信息被舍弃而不是用来凑数，每条陈述都能在原文中找到依据。
